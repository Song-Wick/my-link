## 1. 개요 및 역할 정의

본 문서는 링크트리 클론 서비스 **"마이링크 (My-Link)"**의 핵심 사용자(방문자 및 소유자)가 서비스를 이용하는 구체적인 행동 흐름을 정의합니다. 모든 시나리오 단계는 **"사용자는 [목적]하기 위해 [행동]한다."** 형식으로 기술되었습니다.

### 사용자 역할 (Roles)
- **방문자 (Visitor)**: 소유자의 SNS, 이메일, 이력서 등을 통해 마이링크 웹페이지에 방문하여 콘텐츠를 탐색하고 외부 채널로 이동하는 사용자.
- **소유자 (Owner / Admin)**: Google 계정으로 인증된 1인 관리자로서, 닉네임, 프로필, 링크 아이템을 인라인으로 추가·수정·삭제하고 관리하는 사용자.

## 2. 방문자 시나리오 (Visitor Journey): 페이지 방문 및 탐색 과정

### 2.1 SNS 유입 및 마이링크 페이지 접속
1. **사용자는** 소유자의 다양한 활동 채널을 한곳에서 확인하기 위해 **인스타그램/X(트위터)/깃허브 프로필 소개란의 마이링크 URL을 클릭한다.**
2. **사용자는** 소유자의 기본 정보와 아이덴티티를 파악하기 위해 **화면 상단에 로딩된 프로필 아바타 이미지, 닉네임(`displayName`), 한 줄 소개(Bio)를 확인한다.**

### 2.2 소셜 미디어 채널 바로가기
1. **사용자는** 소유자의 공식 SNS 채널로 즉시 연결하기 위해 **프로필 헤더 하단의 소셜 아이콘 바(GitHub, X, LinkedIn, YouTube, Email) 중 원하는 아이콘을 클릭한다.**
2. **사용자는** 기존 마이링크 페이지를 유지한 채 채널을 확인하기 위해 **새 브라우저 탭으로 열린 대상 소셜 플랫폼 페이지로 이동한다.**

### 2.3 구글 파비콘 연동 링크 아이템 탐색 및 이동
1. **사용자는** 관심 있는 프로젝트나 최신 블로그 글을 찾기 위해 **상하 스크롤을 통해 링크 아이템 목록을 탐색한다.**
2. **사용자는** 해당 링크가 어떤 웹사이트로 연결되는지 직관적으로 인지하기 위해 **각 링크 카드 좌측에 표시된 구글 파비콘(Favicon) 아이콘을 확인한다.**
3. **사용자는** 해당 목적지 사이트의 콘텐츠를 열람하기 위해 **원하는 링크 카드를 클릭한다.**
4. **사용자는** 안전하게 외부 페이지를 탐색하기 위해 **새 탭(`_blank`)으로 열린 목적지 웹사이트로 이동한다.**

### 2.4 마이링크 페이지 주소 복사 및 공유
1. **사용자는** 현재 보고 있는 소유자의 마이링크 페이지를 다른 사람에게 공유하거나 보관하기 위해 **화면 하단 또는 상단의 '링크 복사' 버튼을 클릭한다.**
2. **사용자는** 복사 성공 여부를 직관적으로 인지하기 위해 **화면 하단에 잠시 나타나는 '주소가 클립보드에 복사되었습니다' 토스트 알림을 확인한다.**

## 3. 소유자 시나리오 (Owner Journey): 관리자 인증 및 인라인 관리 과정

### 3.1 Google 소셜 로그인 및 관리자 대시보드 진입
1. **사용자는** 본인의 링크 허브를 관리하기 위해 **관리자 접속 경로(`/admin`)로 이동한다.**
2. **사용자는** 별도의 회원가입이나 복잡한 비밀번호 입력 없이 빠르게 인증하기 위해 **'Google 계정으로 로그인' 버튼을 클릭한다.**
3. **사용자는** 1인 소유자 권한을 승인받기 위해 **사전에 등록된 관리자 전용 Google 이메일 계정을 선택하여 로그인을 완료한다.**
4. **사용자는** 링크 관리 모드로 전환하기 위해 **인증 완료 후 자동으로 진입된 관리자 대시보드 화면을 확인한다.**

### 3.2 닉네임(`displayName`) 및 프로필 인라인 수정
1. **사용자는** 브랜딩 이름이나 닉네임을 변경하기 위해 **화면 상단에 표시된 본인의 닉네임(`displayName`) 텍스트를 직접 클릭한다.**
2. **사용자는** 새로운 활동명을 입력하기 위해 **클릭 즉시 활성화된 인라인 텍스트 입력창에 새 닉네임을 타이핑한다.**
3. **사용자는** 수정된 닉네임을 확정하고 저장하기 위해 **엔터(Enter) 키를 누르거나 입력창 바깥 영역을 클릭(포커스 아웃)한다.**
4. **사용자는** 자기소개 문구를 갱신하기 위해 **한 줄 소개(Bio) 텍스트 영역을 직접 클릭하여 인라인으로 문구를 수정하고 저장한다.**
5. **사용자는** 프로필 사진을 교체하기 위해 **아바타 이미지에 마우스를 올린 후 나타나는 카메라 아이콘을 클릭하여 로컬 기기에서 새 이미지를 업로드한다.**

### 3.3 신규 링크 추가 및 구글 파비콘 자동 연동
1. **사용자는** 새로운 웹사이트 링크를 허브에 등록하기 위해 **링크 목록 상단의 '새 링크 추가' 인라인 입력 폼을 클릭한다.**
2. **사용자는** 방문자에게 보여줄 명칭을 지정하기 위해 **'제목(Title)' 입력 필드에 링크 이름을 타이핑한다.**
3. **사용자는** 이동할 웹사이트 주소를 지정하기 위해 **'URL' 입력 필드에 목적지 주소(`https://...`)를 붙여넣거나 타이핑한다.**
4. **사용자는** 파비콘이 올바르게 추출되었는지 확인하기 위해 **URL 입력과 동시에 구글 파비콘 API를 통해 실시간으로 렌더링되는 파비콘 미리보기를 확인한다.**
5. **사용자는** 신규 링크를 즉시 목록에 등록하기 위해 **엔터(Enter) 키를 누르거나 '추가' 버튼을 클릭한다.**
6. **사용자는** 저장이 정상적으로 완료되었음을 확인하기 위해 **링크 목록 최상단에 새 링크 카드가 즉시 추가되는 것을 확인한다.**

### 3.4 기존 링크 아이템 인라인 수정
1. **사용자는** 이미 등록된 링크의 제목을 변경하기 위해 **해당 링크 카드의 제목 텍스트를 클릭하여 인라인 편집 모드로 전환한다.**
2. **사용자는** 오타를 교정하거나 문구를 다듬기 위해 **입력 필드 내에서 텍스트를 수정한 뒤 엔터(Enter) 키를 누른다.**
3. **사용자는** 연결 주소를 다른 페이지로 바꾸기 위해 **해당 링크의 URL 텍스트를 클릭하여 새로운 웹 주소로 수정하고 저장한다.**
4. **사용자는** 변경된 URL의 파비콘이 정상 반영되었는지 확인하기 위해 **수정 완료 즉시 자동으로 갱신되는 구글 파비콘 아이콘을 확인한다.**

### 3.5 드래그 앤 드롭(DnD) 링크 노출 순서 변경
1. **사용자는** 가장 중요한 링크를 상단에 배치하기 위해 **이동시키고자 하는 링크 카드 좌측의 드래그 핸들 아이콘을 클릭한 채 마우스를 누른다.**
2. **사용자는** 원하는 노출 순서로 이동하기 위해 **카드를 위 또는 아래로 드래그하여 목표 위치로 끌어다 놓는다(Drop).**
3. **사용자는** 변경된 순서가 Firestore 데이터베이스에 즉시 동기화되었음을 확인하기 위해 **화면 하단에 잠시 표시되는 '순서가 저장되었습니다' 안내 토스트를 확인한다.**

### 3.6 링크 노출 비활성화(토글) 및 영구 삭제
1. **사용자는** 링크를 삭제하지 않고 잠시 숨겨두기 위해 **해당 링크 카드 우측의 공개 스위치(`Switch`)를 클릭하여 비활성화(OFF) 상태로 전환한다.**
2. **사용자는** 더 이상 필요 없는 링크를 완전히 제거하기 위해 **해당 링크 카드 우측의 휴지통(삭제) 아이콘을 클릭한다.**
3. **사용자는** 실수로 인한 삭제를 방지하기 위해 **화면에 나타난 확인 안내창에서 '삭제' 버튼을 클릭한다.**
4. **사용자는** 목록에서 깔끔하게 정리되었음을 확인하기 위해 **해당 링크 카드가 화면에서 부드럽게 사라지는 것을 확인한다.**

## 4. 예외 및 실패 대응 시나리오 (Edge Cases)

### 4.1 비인가 Google 계정 로그인 차단
1. **사용자는** 관리자 권한을 획득하기 위해 **소유자 계정이 아닌 다른 개인 Google 계정으로 로그인을 시도한다.**
2. **사용자는** 보안 정책에 의해 접근이 거부되었음을 인지하기 위해 **"관리자 권한이 없는 계정입니다"라는 경고 토스트와 함께 로그인 화면으로 강제 로그아웃 리다이렉트되는 것을 확인한다.**

### 4.2 잘못된 URL 형식 입력 시 오류 처리
1. **사용자는** 링크를 생성하거나 수정할 때 **`https://` 규격에 맞지 않거나 유효하지 않은 도메인을 입력하고 저장을 시도한다.**
2. **사용자는** 올바른 주소로 교정하기 위해 **"올바른 웹사이트 URL을 입력해 주세요"라는 인라인 에러 메시지를 확인하고 올바른 주소를 재입력한다.**

### 4.3 파비콘이 존재하지 않는 웹사이트 링크 등록 시
1. **사용자는** 파비콘이 등록되어 있지 않거나 특수한 도메인의 링크를 등록한다.
2. **사용자는** UI 깨짐 현상 없이 안정적으로 링크를 사용하기 위해 **구글 파비콘 대신 기본 지구본(Globe) 아이콘으로 자동 폴백(Fallback)되어 표시되는 것을 확인한다.**
